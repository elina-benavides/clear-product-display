# Clear Product Display

Oye tengo la siguiente vista quiero que la regreses exactamente igual solo que para la descripción quiero que ocupe toda la primer fila y la segunda fila de cada producto este tal como está ahora el precio y las cantidades y subtotal . Esto es con el fin de que si existen productos con descripciones largas se pueda leer bien. Es posible hacerlo limpio que se vea bien conseva el resto idéntico. Cuida que que no vaya a quedar muy alto cada fila eres el experto en ui tú sabrás las dimensiones y lo que mejor nos conviene te comparto captura
